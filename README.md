## Overview

Microsoft Dynamics NAV Playbook is an independent knowledge base designed to help ERPNext implementors understand and navigate Microsoft Dynamics NAV.

This playbook provides practical references, explanations, and conceptual mappings between ERPNext and Microsoft Dynamics NAV, making the transition between both ERP ecosystems easier to understand.

Whether you are a developer, functional consultant, or ERP implementor, this documentation aims to provide a practical starting point for exploring Microsoft Dynamics NAV.

The documentation is organized into several sections:

## Objectives

- Help ERPNext implementors understand Microsoft Dynamics NAV.
- Explain differences in terminology, configurations, and business processes.
- Provide practical references for common NAV operations.
- Document useful findings and troubleshooting scenarios encountered during implementation.
