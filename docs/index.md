# Microsoft Dynamics NAV Playbook

A Practical Guide to Understanding Microsoft Dynamics NAV if You are an ERPNext Implementor.

## Welcome

Welcome to Microsoft Dynamics NAV Playbook.

This documentation is designed to help ERPNext implementors understand Microsoft Dynamics NAV through practical explanations, module references, and comparisons between both ERP systems.

The language that used in this document is Bahasa Indonesia.

## Documentation Structure

This playbook is organized into the following sections

- **Introduction**: An introduction to Microsoft Dynamics NAV and its mapping
to ERPNext concepts.
- **Master Data**: Understanding master data structures and their relationships
within Microsoft Dynamics NAV.
- **Transaction**: Practical references.
- **Miscellaneous**: Additional references covering customer price groups
and discount groups.

## Purpose

The goal of this playbook is to make the transition from ERPNext to Microsoft Dynamics NAV 
easier by providing a practical knowledge reference for implementors.
